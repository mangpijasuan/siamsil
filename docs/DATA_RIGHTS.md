# Siamsil data rights register

Updated: 2026-10-17
Phase: [ROADMAP.md](ROADMAP.md) Phase 0

One row per source Siamsil holds or plans to use. Nothing here is legal advice; every `needs_review` must be closed by the rights holder's written answer or by counsel, not by an engineer's reading.

## Status values

| Status | Meaning |
|---|---|
| `needs_review` | Rights unknown. May be used internally for retrieval with labels; not for training, redistribution, or commercial use. |
| `cleared` | Written permission or a verified open license covers the listed uses. Record the evidence. |
| `restricted` | Some uses allowed, others not. List both. |
| `blocked` | Must not be used. |

Uses are checked separately: **display** (show in the app), **train** (model training), **redistribute** (publish datasets or weights), **commercial** (paid API or product).

## Language code

The pipeline stores Zomi text with the code `zom` (for example `target_language` in `build_language_db.py`). In ISO 639-3, `zom` is **Zou**, a different Kuki-Chin language. Tedim, the language Zolai/Zomi writing is based on, is `ctd`.

**Decision (2026-10-04, project owner):** Siamsil labels its Zomi text `zom`. `ctd` (Tedim) is the reference code for source material, such as Tedim Bible text, that is being transferred into Siamsil's Zomi.

- Stored data, API responses, and dataset records keep `zom`; no migration is planned.
- Source records that are Tedim text before transfer are described as `ctd` in their provenance.
- Because ISO 639-3 assigns `zom` to Zou, outside tools (dataset hubs, language-ID models, translation benchmarks) will read `zom` as Zou. Every published dataset, model card, or API document must say so explicitly, for example: "`zom` is Siamsil's label for Zomi (Tedim-based, related ISO 639-3 code `ctd`); it is not ISO 639-3 Zou."

## Closing an item

1. Record the evidence (email, signed agreement, license URL and version) in this file with the date.
2. Update the matching `data/raw/**/provenance.json` `license` field, and the `train` status in `data/rights.json`, which `export_datasets.py` enforces.
3. Update the table above. A change to `cleared` needs a second person to confirm.
