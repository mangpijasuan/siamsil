# Siamsil data rights register

Updated: 2026-10-04
Phase: [ROADMAP.md](ROADMAP.md) Phase 0

One row per source Siamsil holds or plans to use. Nothing here is legal advice; every `needs_review` must be closed by the rights holder's written answer or by counsel, not by an engineer's reading.

## Status values

| Status | Meaning |
|---|---|
| `needs_review` | Rights unknown. May be used internally for retrieval with labels; not for training, redistribution, or commercial use. |
| `cleared` | Written permission or a verified open license covers the listed uses. Record the evidence. |
| `restricted` | Some uses allowed, others not. List both. |
| `blocked` | Must not be used. |

Uses are checked separately: **display** (show in the app), **train** (model training), **redistribute** (publish datasets or weights), **commercial** (paid API or product).

## Open questions, by source

**Dictionary**
- Who compiled the Zomi Standard Dictionary, and who holds copyright?
- The filename says "AI Cleaned". Which model or tool changed it, and which fields did it change? Rows with `Flagged` and `Suggested Correction` suggest the changes are partly recorded.
- Will the rights holder allow training and redistribution, and on what attribution terms?

**Parallel corpus, English side**
- Tatoeba publishes sentences under CC-BY 2.0 FR, with some under CC0. Confirm the license of the OPUS release used and record the attribution text required.

**Parallel corpus, Zomi side**
- Which accounts and terms of service were in force when each Gemini model generated output (`gemini-pro`, `gemini-2.5-flash`, `gemini-3-flash-preview`, `gemini-3-pro-preview`)?
- Do those terms allow using the output to train another translation model, and to offer that model commercially? Until answered, generated Zomi must not train any model offered through a paid API.

**Bible**
- Which Zomi translation is the "Original ZSF Text", and who holds its copyright? Bible societies usually license scripture text explicitly, even for display.
- Who produced the "ISO Improved Text", by what process (human or model), and does the copyright holder accept modified text being shown?
- KJV is public domain in most countries but is under Crown letters patent in the United Kingdom. Confirm this does not affect intended uses.
- Only the human-authored column should be treated as human-made data for training; the "improved" column needs its own review.

**Daily-use phrases**
- Confirm the teacher who reviewed them agrees to their use in training and redistribution, and how they want to be credited.

## Language code

The pipeline stores Zomi text with the code `zom` (for example `target_language` in `build_language_db.py`). In ISO 639-3, `zom` is **Zou**, a different Kuki-Chin language. Tedim, the language Zolai/Zomi writing is based on, is `ctd`.

Decision needed from native-speaker editors: which ISO 639-3 code correctly describes Siamsil's Zomi text (likely `ctd`). Until decided:

- keep `zom` internally so existing databases and API responses do not change;
- never publish a dataset, model card, or API documentation that labels Zomi as `zom`;
- after the decision, migrate the stored code in one versioned language release.

## Closing an item

1. Record the evidence (email, signed agreement, license URL and version) in this file with the date.
2. Update the matching `data/raw/**/provenance.json` `license` field.
3. Update the table above. A change to `cleared` needs a second person to confirm.
