# Siamsil data rights register

Updated: 2026-10-25
Phase: [ROADMAP.md](ROADMAP.md) Phase 0

One row per source Siamsil holds or plans to use. Nothing here is legal advice; every `needs_review` must be closed by the rights holder's written answer or by counsel, not by an engineer's reading.

## Status values

| Status | Meaning |
|---|---|
| `needs_review` | Rights unknown. May be used internally for retrieval with labels; not for training, redistribution, or commercial use. |
| `cleared` | Written permission or a verified open license covers the listed uses. Record the evidence. |
| `restricted` | Some uses allowed, others not. List both. |
| `blocked` | Must not be used. |

Uses are checked separately: **display** (show in the app), **train** (model training), **redistribute** (publish datasets or weights), **commercial** (paid API or product).

## Language code

**Decision (2026-10-27, project owner):** Siamsil labels Zomi **`ctd`**, the ISO 639-3 code for Tedim, the language Zolai/Zomi writing is based on. This replaces the 2026-10-04 decision to label it `zom`, which ISO 639-3 assigns to **Zou**, a different Kuki-Chin language.

- Code, stored data, API values, and dataset records use `ctd`: Bible versions (`language_iso`), corpus pairs (`target_language`), user locales, quality-gate records (`origin_language`), the model's language token (`ctd_Latn`), and the HTML `lang` attribute. Translation and dictionary directions are `en-ctd` and `ctd-en`.
- Hugging Face dataset and model cards declare `language: [ctd]` and name the language "Zomi (Zolai), Tedim-based". Declaring `zom` would list the data under Zou.
- Kept for links and databases from before the change: the API still accepts the directions `en-zom` and `zom-en`, the website still opens `?dir=zom-en` links, Bible databases imported before 2026-10-27 have their `zom` versions served as `ctd` until they are rebuilt, and migration `20261027_0004` relabels stored user locales. Rebuild the language and Bible databases (`build_language_db.py`, `import_usx_bibles.py`) to store `ctd`.
- The interface still says "Zomi"; `ctd` is a code, not a name shown to people.

## Non-profit use

**Decision (2026-10-17, project owner):** Siamsil is a non-profit app, offered free of charge.

- Licenses that allow only non-commercial use are acceptable for Siamsil, including NLLB-200 model weights (CC BY-NC 4.0) and the Bible permissions recorded above.
- "Non-commercial" describes how the app is used, not only who runs it. Donations are fine. Paid features, a paid API, advertising, or selling data or models would be commercial use: before adding any of them, review every non-commercial license and permission in this register.

## Closing an item

1. Record the evidence (email, signed agreement, license URL and version) in this file with the date.
2. Update the matching `data/raw/**/provenance.json` `license` field, and the `train` status in `data/rights.json`, which `export_datasets.py` enforces.
3. Update the table above. A change to `cleared` needs a second person to confirm.
